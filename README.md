## github.com/nhelm/bioe591-git Repository

This repository documents my initial attempts at using Git and GitHub.

## Repository Structure

- `README.md`
The file you are currently reading. It describes the structure and contents of the `bioe591-git` repository on GitHub.

- `homework/` 
This subdirectory contains all assignments for the course, organized by assignment number.  
Each assignment has its own subfolder (`01`, `02`, `03`, etc.), which contains the
relevant scripts, output files, and logs for that assignment (e.g.,
`01_Homework_Helmstetter.sh`, `03_Homework_Helmstetter.sbatch`, `.fastq`, `.html`).
